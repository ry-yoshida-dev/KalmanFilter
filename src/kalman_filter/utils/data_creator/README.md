# data_creator

## Overview

This folder contains programs for creating test data for Kalman filter operations.

## Components

| Component | Description |
|-----------|-------------|
| [container.py](./container.py) | Container class for test data |
| [data_creator.py](./data_creator.py) | Program for creating test data |
| [data_type.py](./data_type.py) | Program that defines data types for test data |
