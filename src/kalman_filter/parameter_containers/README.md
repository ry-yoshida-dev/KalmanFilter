# parameter_containers

## Overview

This folder contains Container class programs for KF's main parameters.

## Components

| Component | Description |
|-----------|-------------|
| [base.py](./base.py) | Base class for parameter containers |
| [control_input_matrix.py](./control_input_matrix.py) | Container class for control input matrix |
| [control_input_vector.py](./control_input_vector.py) | Container class for control input vector |
| [error_covariance_matrix.py](./error_covariance_matrix.py) | Container class for error covariance matrix |
| [innovation_covariance_matrix.py](./innovation_covariance_matrix.py) | Container class for innovation covariance matrix |
| [kalman_gain.py](./kalman_gain.py) | Container class for Kalman gain |
| [measurement_matrix.py](./measurement_matrix.py) | Container class for measurement matrix |
| [measurement_noise_covariance.py](./measurement_noise_covariance.py) | Container class for measurement noise covariance |
| [measurement_vector.py](./measurement_vector.py) | Container class for measurement vector |
| [process_noise_covariance.py](./process_noise_covariance.py) | Container class for process noise covariance |
| [process_noise_gain.py](./process_noise_gain.py) | Container class for process noise gain |
| [state_transition_matrix.py](./state_transition_matrix.py) | Container class for state transition matrix |
| [state_vector/](./state_vector/) | Folder containing state vector related programs |
| [utils/](./utils/) | Folder containing utility programs for parameter containers |
